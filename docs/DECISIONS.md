# HeadlessHQ — DECISIONS

<!-- Append-only. Формат фиксирован. -->

## 2026-11-06: Автоматизация как надстройка, не замена

**Контекст:** Ручной Штаб работает (человек открывает кодовые сессии фразой-запуском).
Возник соблазн перевести всё на автозапуск.

**Решение:** HeadlessHQ — добавление поверх того же файлового протокола. Ручной режим
остаётся запасным путём и режимом для неоднозначных работ.

**Альтернативы:** Полная замена ручного режима; два параллельных протокола.

**Trade-off:** Двойной путь запуска (вручную и скриптом) вместо одного. Выигрыш —
откат к ручному режиму при любой поломке автоматизации без переписывания заданий.

## 2026-11-06: Файл задачи как единственный контракт

**Контекст:** Штаб запускает сессию субпроцессом и не видит её контекст.

**Решение:** Обмен только через `docs/tasks/NNNN-*.md` (задание вниз, отчёт вверх).
Stdout сессии — вторичен, машиночитаемым сигналом служит exit-код.

**Альтернативы:** Опрос через server API; парсинг `--format json` как основной канал.

**Trade-off:** Теряем гранулярность промежуточных событий. Выигрыш — протокол не зависит
от API и одинаково работает в ручном и авто режимах.

## 2026-11-06: Безопасность через deny-лист

**Контекст:** В неинтерактивном `run --auto` все `ask` превращаются в allow.

**Решение:** Безопасность держится на явных `deny` (деструктивный bash, выход за репо
через `external_directory`, инструмент `question`), всё остальное разрешено через auto.

**Альтернативы:** Белый список разрешённых команд (хрупко, душит работу);
интерактивные подтверждения (сессия встанет и умрёт по таймауту).

**Trade-off:** Пропущенный в deny-классе деструктив разрешён молча. Компенсация —
одно репо на сессию и приёмка по фактам до слияния последствий дальше.

## 2026-11-06: Сторож v1 синхронный, v2 опросом

**Контекст:** Нужен предел зависшей сессии, но штаб должен оставаться отзывчивым.

**Решение:** v1 — блокирующий `opencode run` с таймаутом shell-вызова (барьер бесплатный).
v2 — detached-запуск плюс опрос статусов (штаб отзывчив, сессии видны в Desktop).

**Альтернативы:** Сразу detached с опросом (сложнее, больше мест отказа на старте).

**Trade-off:** v1 блокирует штаб на время номера. Принято: номера короткие, а простота
v1 даёт рабочий контур, который v2 потом не ломает, а дополняет.
